# РАКОВАРНЯ 73 — Premium Food E-commerce

Самостоятельный прототип премиальной раковарни для Ульяновска и области. Рабочее название бренда и стартовые цены выбраны как проектные допущения, а не как подтверждённые сведения действующего бизнеса.

## Принятая концепция
- **Бренд:** РАКОВАРНЯ 73
- **Регион запуска:** Ульяновск и Ульяновская область
- **Позиционирование:** живые и варёные раки, фирменные рецепты, наборы для встреч и мероприятий
- **Визуальный язык:** Dark Editorial / Quiet Luxury, графитовый и глубокий зелёный, молочный текст, бронзовые акценты
- **Тон коммуникации:** гастрономичный, уверенный, без неподтверждённых обещаний о происхождении и качестве продукта

## Запуск
Требуется Node.js 20 или новее.
```bash
npm install
npm run dev
```
Production-сборка:
```bash
npm run build
npm run preview
```

## Реализовано
- Адаптивная главная страница с editorial-композицией.
- Hero-слайдер с автоматическим переключением и ручной навигацией.
- Каталог с фильтрами по категориям.
- Добавление товаров, изменение количества и корзина с localStorage.
- Калькулятор ориентировочного количества раков.
- Форма заказа с проверкой данных.
- Серверный расчёт цен по ID товара в `api/order.ts`.
- Форма заказа формирует письмо через `mailto:`; отправка не происходит автоматически.
- Мобильная навигация и нижняя панель действий.
- Уважение `prefers-reduced-motion`.

## Где менять каталог и цены
Каталог отображения находится в `src/App.tsx`, серверный каталог для расчёта заказа — в `api/order.ts`. При изменении цены обязательно обновляйте оба места. Сервер не принимает цену из браузера.

## Публикация напрямую через GitHub Pages (без Vercel и Cloudflare)

В репозитории настроен GitHub Actions workflow `.github/workflows/deploy-pages.yml`: при каждом push в `main` он устанавливает зависимости, собирает сайт и публикует папку `dist` в GitHub Pages.

1. Откройте репозиторий: https://github.com/marcostavar24633-cyber/raki
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions** и сохраните.
4. Откройте вкладку **Actions**, выберите workflow **Deploy to GitHub Pages** и дождитесь зелёного статуса.
5. Адрес проекта: https://marcostavar24633-cyber.github.io/raki/

Vite настроен на путь `/raki/`, необходимый для публикации проекта в подпапке GitHub Pages. После каждого следующего push сайт будет обновляться автоматически.

### Как работает заявка

Текущая форма сайта использует `mailto:`. Серверные обработчики Telegram в репозитории не подключены к текущему интерфейсу. Сайт не выполняет автоматическую отправку на сервер. После заполнения формы браузер открывает почтовое приложение с подготовленным письмом: состав заказа, количество, предварительная сумма, имя, телефон и комментарий. Покупатель должен проверить адрес получателя и нажать «Отправить» самостоятельно. Пока письмо не отправлено из почтового приложения, заявка не доставлена продавцу.

Адрес электронной почты продавца пока не указан, поэтому поле получателя в письме остаётся пустым. Для полноценного приёма заявок нужно указать рабочий адрес или подключить и протестировать серверный канал отправки.

## Что обязательно заменить перед коммерческим запуском
- Подтвердить цены, состав набора и синхронизировать серверные каталоги в `api/order.ts` и `functions/api/order.ts` с витриной.
- Демонстрационные фотографии на реальные фотографии ассортимента.
- Реальные контакты, график, адрес/зону доставки и стоимость доставки.
- Тексты о происхождении, свежести и способе хранения — только на подтверждённые.
- Политику обработки персональных данных, согласие, реквизиты оператора и юридические документы.
- Настройки Telegram и фактическую проверку получения заказа.

## Публикация

Для текущей версии используйте Cloudflare Pages по инструкции выше. Не добавляйте `.env.local`, токен бота или реальные персональные данные в GitHub.

Примечание: production-сборка в текущей среде не подтверждена, так как npm registry недоступен. GitHub Actions выполнит независимую сборку после публикации исходников.
